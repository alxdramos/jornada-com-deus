## User Story

**Como** usuario do app Jornada com Deus,
**Quero** acessar meditacoes guiadas na aba Explorar com audio, imagem e descricao,
**Para que** eu possa praticar meditacao crista diariamente usando conteudo atualizado automaticamente da planilha do Google Sheets.

---

## Descricao

### Contexto

O app Jornada com Deus ja possui 17+ meditacoes hardcoded em `/src/data/meditacoes.ts` com URLs de imagem externas (Unsplash) e audio no Cloudflare R2. A aba Explorar (`TabExplorar.tsx`) ja renderiza essas meditacoes usando componentes prontos (`MeditationCard`, `ContentSection`, `AllContentModal`, `MeditationPlayer`).

O problema eh que os dados estao hardcoded. Precisamos criar um script de sincronizacao (`sync-meditacoes.ts`) identico ao padrao ja existente para oracoes (`sync-oracoes.ts`), que busca dados do Google Sheets e gera o arquivo TypeScript automaticamente.

### Estrutura do Google Sheets — Aba "Meditacoes"

A planilha (`10Sla_3_ic0ZZ9WfKhaHcpnjhj6dddYa-O-oFPVkzs9Q`) possui uma aba chamada **"Meditacoes"** (ou similar — confirmar nome exato) com as seguintes colunas esperadas:

| Coluna | Conteudo | Obrigatoria |
|--------|----------|-------------|
| A | Titulo | Sim |
| B | Texto/Descricao | Sim |
| C | Audio URL (R2) | Sim |
| D | Imagem (nome do arquivo ou URL) | Nao (fallback para ImageMapper) |
| E | Duracao (ex: "8 min") | Nao (fallback "--:--") |
| F | Categoria (MENTE, CORPO, ESPIRITO, etc.) | Nao (fallback "MENTE") |
| G | Tags (separadas por virgula) | Nao (fallback []) |
| H | Plus (TRUE/FALSE) | Nao (fallback false) |

> **IMPORTANTE**: A estrutura exata das colunas DEVE ser confirmada antes de implementar. O @dev deve inspecionar a planilha e ajustar os indices de coluna conforme necessario.

## Criterios de Aceitacao

### AC-1: Script de sincronizacao busca dados do Google Sheets
```
DADO que o arquivo de credenciais Google existe em `jornadacomdeus-ce9c0e55fc3e.json`
E a planilha `10Sla_3_ic0ZZ9WfKhaHcpnjhj6dddYa-O-oFPVkzs9Q` esta acessivel
QUANDO executo `npx tsx scripts/sync-meditacoes.ts`
ENTAO o script busca todas as linhas da aba "Meditacoes"
E ignora linhas sem titulo, texto ou audioUrl
E imprime no console o total de meditacoes processadas
```

### AC-2: Dados sao salvos no formato MeditationCard existente
```
DADO que o script processou N meditacoes validas
QUANDO o arquivo `src/data/meditacoes.ts` eh gerado
ENTAO ele exporta a interface `MeditationCard` com os campos: id, title, duration, category, plus, description, tags, image, audioUrl
E exporta `MEDITACOES` como `MeditationCard[]` com N itens
E exporta `MEDITACOES_COUNT` com o valor N
E mantem as constantes `CATEGORIAS`, `CHIPS`, `LIVROS_AT`, `LIVROS_NT` inalteradas
E mantem os arrays `CARDS_ESCRITURAS` e `CARDS_NOVO` inalterados
```

### AC-3: IDs sao gerados de forma deterministica
```
DADO uma meditacao com titulo "Renovacao Sob o Ceu Infinito"
QUANDO o ID eh gerado
ENTAO o resultado eh "renovacao-sob-o-ceu-infinito"
E o ID eh lowercase, sem acentos, com hifen separando palavras
E o ID eh unico dentro do array MEDITACOES
```

### AC-4: Imagens sao mapeadas usando ImageMapper existente
```
DADO que uma meditacao NAO tem imagem definida na planilha
QUANDO o ImageMapper processa a meditacao
ENTAO uma imagem da pasta `/public/images/` eh atribuida aleatoriamente sem repeticao
E o campo `image` recebe o caminho `/images/{nome_arquivo.png}`

DADO que uma meditacao TEM uma URL de imagem definida na planilha
QUANDO o script processa a meditacao
ENTAO o campo `image` recebe a URL da planilha diretamente
```

### AC-5: Tags e categorias sao processadas corretamente
```
DADO uma meditacao com tags "PAZ, ANSIEDADE, DORMIR" na planilha
QUANDO o script processa
ENTAO o campo `tags` eh ["PAZ", "ANSIEDADE", "DORMIR"]
E cada tag eh trimmed e uppercase

DADO uma meditacao com categoria "corpo" na planilha
QUANDO o script processa
ENTAO o campo `category` eh "CORPO" (uppercase)
```

### AC-6: Campo plus eh processado corretamente
```
DADO uma meditacao com plus = "TRUE" ou "true" ou "1" na planilha
QUANDO o script processa
ENTAO o campo `plus` eh `true` (boolean)

DADO uma meditacao sem valor no campo plus
QUANDO o script processa
ENTAO o campo `plus` eh `false` (boolean)
```

### AC-7: SheetsClient recebe metodo fetchMeditacoes
```
DADO o arquivo `src/lib/sheets-client.ts`
QUANDO o metodo `fetchMeditacoes()` eh chamado
ENTAO ele busca dados da aba "Meditacoes" (range configuravel)
E retorna array de `MeditacaoSheetRow` com campos: titulo, texto, audioUrl, imagem?, duracao?, categoria?, tags?, plus?
E o metodo `fetchOracoes()` existente NAO eh alterado
```

### AC-8: Arquivo JSON publico eh gerado
```
DADO que o script processou meditacoes
QUANDO a sincronizacao completa
ENTAO o arquivo `public/data/meditacoes.json` eh criado/atualizado
E contem os mesmos dados do TypeScript em formato JSON
```

### AC-9: Workflow do GitHub Actions funciona
```
DADO o arquivo `.github/workflows/sync-meditacoes.yml`
QUANDO eh acionado manualmente (workflow_dispatch) ou por cron
ENTAO executa `npm run sync:meditacoes`
E faz commit e push se houver mudancas
E os arquivos commitados sao: src/data/meditacoes.ts, public/data/meditacoes.json
```

### AC-10: Build passa sem erros
```
DADO que o script gerou o novo `src/data/meditacoes.ts`
QUANDO executo `npm run build`
ENTAO nao ha erros de TypeScript
E nao ha erros de lint
E a interface `MeditationCard` existente eh preservada
E todos os componentes que importam de `@/data/meditacoes` continuam funcionando
```
