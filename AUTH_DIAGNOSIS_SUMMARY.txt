DIAGNÓSTICO RÁPIDO: Loop de Autenticação "Jornada com Deus"
Data: 22/02/2026
================================================================================

PROBLEMA RAIZ:
  NextAuth v5 beta SEM persistência de sessão + Vercel cache CDN = loop infinito

RAIZ CAUSA TÉCNICA:
  1. NextAuth configurado com JWT-only (sem banco de dados)
  2. Session callbacks criam JWT, mas NÃO persistem no servidor
  3. Vercel serve home.tsx como static cache (x-nextjs-prerender: 1)
  4. Middleware valida auth, mas cache serve página cacheada anyway
  5. Usuario sem sessão persistida = loop: login → redireciona → cache → sem auth
